# NixOS-configuration
This is my personal NixOs configuration meant to bring up to speed any computer that I own with my preferred environments, workflows and settings. 

The configuration started out in my laptop which I mainly use for studying, allowing me to keep me separated from gaming or other things that could potentially be distracting.

It will be expanded along the way as my needs evolve. It will also be improved adding new features and improving the modularity and efficiency the configuration.
